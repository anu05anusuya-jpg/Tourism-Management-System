
# ✈️ Tourism Management System

## 📌 Project Overview

The Tourism Management System is a Java-based application designed to manage tourism packages, tourist information, and booking details. It demonstrates the practical implementation of Object-Oriented Programming (OOP) concepts using Core Java.

## 🎯 Project Objectives

- Manage tourist information.
- Organize domestic and international tourism packages.
- Calculate package costs based on travel duration and number of travelers.
- Apply discounts based on booking duration.
- Demonstrate OOP concepts through a real-world use case.

## ✨ Features

- Display tourist details.
- Manage tourism package information.
- Support domestic and international tourism packages.
- Calculate booking costs based on the number of travelers and travel days.
- Apply discounts for eligible bookings.
- Calculate additional charges for luxury packages.
- Display booking details and final package costs.

## 🛠️ Technologies Used

- Java
- Core Java
- Object-Oriented Programming (OOP)
- IntelliJ IDEA

## 🧠 OOP Concepts Used

- **Abstraction:** Defines common tourism package behaviour.
- **Inheritance:** Reuses common properties across package types.
- **Encapsulation:** Organizes tourism and booking data.
- **Polymorphism:** Supports different tourism package implementations.
- **Method Overriding:** Provides package-specific behaviour.

## ⚙️ Prerequisites

- Java Development Kit (JDK)
- IntelliJ IDEA or another Java IDE

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA.
3. Configure a compatible JDK.
4. Run the `TourismManagementApp` main class.
5. Enter the required booking details if prompted.
6. View the package cost and booking summary.

## 📊 Sample Calculation

For example, a luxury tourism package may include:

- Package cost
- Number of travelers
- Travel duration
- Applicable discount
- Luxury surcharge
- Final booking amount

*The final amount depends on the package and booking details entered.*
